## Definicion base

### Definición
Framework de 5 etapas de crecimiento: Acquisition (conseguir users), Activation (first success), Retention (vuelven), Referral (traen amigos), Revenue (generan dinero). AARRR mide salud de crecimiento en cada etapa.

### Propósito Principal
Identificar dónde el funnel tiene más fricción. Optimizar cada etapa. Escalar crecimiento sistemáticamente.

### Pilares Principales
1. **Acquisition**: CAC, CAC payback, tráfico
2. **Activation**: Time to first value, onboarding
3. **Retention**: 30-day retention, churn rate
4. **Referral**: Viral coefficient, NPS
5. **Revenue**: ARPU, LTV, LTV:CAC ratio

### Aplicación Práctica
- Acquisition: Focus on CAC &lt;$100
- Activation: Reduce time to first value &lt;10 min
- Retention: Target >40% month 3 retention
- Referral: Build viral loops, NPS >50
- Revenue: Target LTV:CAC >3:1

### ROI Típico
+50% growth hacking velocity

## Guia operativa MEO

Este bloque convierte la informacion local anterior en una secuencia accionable para la plataforma.

### Proposito dentro del sistema

AARRR Framework (Pirate Metrics) funciona como modulo de diagnostico, posicionamiento, planificacion y alineacion del equipo. En MEO no debe quedar como concepto aislado: debe conectarse con adquisicion, experiencia, datos y optimizacion continua.

### Aplicacion practica

1. Definir objetivo principal del framework y el resultado de negocio esperado.
2. Levantar baseline: estado actual, canales implicados, activos disponibles y brechas.
3. Mapear dependencias MEO: frameworks previos, datos necesarios, herramientas y responsables.
4. Ejecutar un sprint inicial de 2 a 4 semanas con entregables visibles.
5. Medir avance con KPIs semanales y documentar aprendizajes.
6. Integrar lo que funcione a la ruta ecommerce, startups y escalarlo como proceso repetible.

### KPIs sugeridos

- Impacto principal: mejora porcentual contra baseline del objetivo definido.
- Velocidad de implementacion: dias desde diagnostico hasta primera ejecucion medible.
- Calidad del activo: completitud, consistencia y cumplimiento del checklist MEO.
- Contribucion al funnel: trafico, engagement, conversion, retencion o eficiencia segun el caso.
- Sinergia: numero de frameworks MEO conectados con datos, contenido o automatizacion.

### Entregables minimos

- Diagnostico inicial y matriz de oportunidades.
- Checklist de implementacion por canal o activo.
- Dashboard simple con baseline, meta, avance y proximo experimento.
- Retro semanal con aprendizajes, bloqueos y siguiente iteracion.
