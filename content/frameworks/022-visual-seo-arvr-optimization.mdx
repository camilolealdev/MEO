## Definición
Visual SEO mejora la descubribilidad y comprensión de imágenes y vídeo. AR/VR se incluye solo cuando resuelve una tarea concreta; no es una señal de ranking por sí misma.

## Propósito
Conectar cada recurso visual con una página útil, contexto textual, accesibilidad y una acción medible.

## Cuándo usarlo
- Cuando el usuario necesita ver un producto, espacio, proceso o resultado.
- Cuando imágenes o vídeos ya generan impresiones o asistencia a conversiones.

## Pasos
1. Define la tarea que el medio debe resolver.
2. Publica el recurso en HTML rastreable con contexto y texto alternativo.
3. Usa formatos, dimensiones, compresión y URLs estables.
4. Para vídeo, añade página de reproducción indexable y miniatura.
5. Para AR/VR, ofrece alternativa 2D y controles accesibles.
6. Valida en móvil y con conexión limitada.

## KPIs
- Impresiones, clics y CTR de imágenes o vídeos.
- Carga, interacción y abandono.
- Conversiones asistidas.
- Errores de indexación, accesibilidad y rendimiento.

## Límites
Google no indexa imágenes CSS como elementos `img`, y la indexación de vídeo depende de requisitos concretos. Ningún formato garantiza ranking.
